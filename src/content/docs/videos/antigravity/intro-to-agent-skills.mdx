## Description

Introducing Agent Skills, a breakthrough method for giving your AI agent access to vast, specialized knowledge that only activates precisely when the task requires it. You’ll learn how to move beyond simple code completion by creating modular, on-demand skills that provide the deep context necessary for complex, modern development.

Agents operate across the editor, terminal, and browser, enabling them to autonomously plan and execute complex, end-to-end tasks elevating all aspects of software development.
